# 🏡 LuxeEstate - Real Estate Website with Mortgage Calculator

Премиальный многостраничный сайт агентства недвижимости. Главная фишка — интерактивный калькулятор ипотеки с кастомными ползунками (Range Sliders) и моментальным пересчетом ежемесячного платежа.

## 🔥 Особенности проекта

*   **Сложная математика в JS:** Реализован алгоритм расчета аннуитетного платежа по формуле.
*   **Интерактивный UI:** Кастомные ползунки (Range Slider), которые меняют значения в реальном времени. Ползунок первоначального взноса ограничен стоимостью объекта.
*   **Форматирование чисел:** Автоматическое добавление пробелов в большие числа (например, 10 000 000) для удобства чтения.
*   **Премиальный дизайн:** Использование элегантных шрифтов (Playfair Display для заголовков) и глубоких зеленых акцентов.
*   **Адаптивность:** Все элементы, включая калькулятор, корректно перестраиваются на мобильных устройствах.

## 🛠 Технологии
*   HTML5 (Семантическая верстка)
*   CSS3 (Grid, Flexbox, кастомизация `input[type=range]`)
*   Vanilla JavaScript (DOM, Events, Math)

## 🚀 Как запустить
Просто откройте `index.html` в браузере и попробуйте подвигать ползунки в калькуляторе!

Премиальный многостраничный сайт агентства недвижимости с интерактивным калькулятором ипотеки.

![LuxeEstate Real Estate](![Uploading screenshot.png…])

## 🔥 Особенности проекта

- **Сложная математика в JS** — алгоритм расчета аннуитетного платежа по формуле
- **Интерактивный UI** — кастомные ползунки (Range Slider), меняющие значения в реальном времени
- **Форматирование чисел** — автоматическое добавление пробелов в большие числа для удобства чтения
- **Премиальный дизайн** — шрифты Playfair Display, глубокие зелёные акценты
- **Адаптивность** — корректное отображение на мобильных устройствах

## 🛠 Технологии

- **HTML5** — семантическая верстка
- **CSS3** — Grid, Flexbox, кастомизация `input[type=range]`
- **Vanilla JavaScript** — DOM, Events, Math

## 🚀 Как запустить

Просто откройте `index.html` в браузере и попробуйте подвигать ползунки в калькуляторе ипотеки!
